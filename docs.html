Getting started

  1. Install ImageTextLab and open it from Shopify admin.
  2. Confirm Shopify managed billing or start the free trial.
  3. Open the Scan view and run a store scan.
  4. Review generated alt text tasks before writing approved updates back to Shopify.
  5. Use SEO and Audit views to review metadata suggestions and accessibility issues.

Settings

Merchants can adjust generation tone, maximum alt text length, and safety preferences before creating future AI tasks.

Logs

The Logs view records app loads, tab navigation, button actions, API responses, OAuth events, webhooks, and UI errors for troubleshooting.
