ImageTextLab screencast

This short demo shows the embedded Shopify admin experience for dashboard review, store scanning, generated alt text tasks, accessibility audit, settings, billing, and logs.

Review steps shown

  1. Open ImageTextLab from Shopify Admin.
  2. Review dashboard metrics and billing state.
  3. Run a store scan for images missing alt text.
  4. Generate and review AI alt text tasks before writeback.
  5. Open Audit, Settings, Billing, and Logs for supporting review screens.
