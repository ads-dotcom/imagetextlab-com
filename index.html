Security and scope

Focused permissions, clear processing

ImageTextLab is designed around image metadata and content workflows. It does not request protected customer data, and generated text stays reviewable before merchant approval.

Works with product, file, collection, article, and page image metadata.

Stores operational data on Cloudflare infrastructure for support and audit history.

Uses configured AI processing only when merchants request generation.

Supports mandatory Shopify privacy and compliance webhooks.
